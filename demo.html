What this guard can see

POST likes, unlikes, and GraphQL requests to Instagram’s web endpoints. Explicit queries pass through; unnamed GraphQL POSTs require a decision. Request values stay hidden.

This is a convenience guard in the page’s JavaScript environment. Endpoint changes, cached native functions, workers, forms, and other network channels can bypass it. It is not an account security boundary.
